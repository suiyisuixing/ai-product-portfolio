## 二、需求阶段标注说明

各份 PRD 对功能需求与迭代项区分以下四类里程碑状态：

| 状态标签 | 含义 |
| --- | --- |
| `[已上线]` / `[已实现]` | 已在当前正式站或原型版本中实现并完成功能验证。 |
| `[V2 迭代规格]` | 针对实测发现的交互或口径问题输出的详细产品规格，作为下一版本迭代依据。 |
| `[后续规划]` | 后续里程碑扩展能力、埋点方案与规模化评测规划。 |

## 三、跨文档核心基线

以下为三线产品与 [四页作品集](../portfolio/yu-wei-portfolio.pdf) 及案例页共同遵循的核心口径基线：

- **QuantLab**：6 只研究 ETF、1,416 个共同有效交易日（含 2020 预热期）、1,211 个回测交易日（2021–2025）、单边 5 bps 交易成本、当前策略与 4 条基准曲线、双记录回撤口径对照（全期 A 48.87% vs B 48.49%；2025 留出期 A 17.86% vs B 20.10%，并列展示列入 V2 规格）、60 题标准答案评测集与自动判分脚本，以及团队汇总的 10 位组外匿名试用反馈迭代。
- **ClassNote AI**：macOS 本地优先桌面工作台（已完成 macOS DMG 安装版课堂实测与恢复验收，另含 Windows PyInstaller 打包配置规格），`faster-whisper` 5 档模型（默认 Base），真实故障驱动开课前预检与三状态解耦，历史续录恢复找回约 76.8 分钟有效录音（461 分片、0 重复字幕）。
- **AppliedAI & ServeTrace**：本地 `Qwen3.5-27B` + `BAAI/bge-small-zh-v1.5` 端到端引用溯源与无依据拒答；5 篇分密级演示文档正反对照验证检索层隔离规则（未授权 0/9、授权 9/9、公开题双身份 2/2）；工具异常兜底与网关限流追踪闭环。
