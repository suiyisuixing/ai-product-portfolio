## 二、文档状态图例与事实边界约定

为避免将“已运行功能”与“待研发迭代规格”混淆，所有 PRD 均对每条需求、验收用例和埋点事件强制标注以下四类状态标签：

| 状态标签 | 严格含义 |
| --- | --- |
| `[已落地·已验证]` | 已在当前版本代码中实现，且具备对应实测截图、自动化测试或验收报告证据。 |
| `[已落地·待复测]` | 功能已在当前版本交付或上线，但尚未补齐逐人量化复测、真实双账号切换或全量端到端回归。 |
| `[本版规格·待研发落地]` | 针对已暴露 Badcase、截图体验问题或治理缺口输出的可直接开发规格，**尚未合入当前线上/本地运行态**。 |
| `[规划·P1/P2]` | 后续里程碑能力、埋点采集与评测扩展规格；明确标注为待接入规划，**不代表已有生产数据**。 |

## 三、跨文档口径一致性基线

本目录所有数据、口径与限制边界均与主简历、[四页作品集](../portfolio/yu-wei-portfolio.pdf) 及三个案例页保持单一真源对齐：

- **QuantLab**：6 只研究 ETF、1,416 个共同有效交易日（含 2020 预热期）、1,211 个回测交易日（2021-01-04 至 2025-12-31）、单边 5 bps 交易成本（买卖各按成交额计费 0.05%）、2026-11-19 双记录回撤口径对照（全期 A 48.87% vs B 48.49%；留出期 A 17.86% vs B 20.10%）、10 位组外匿名试用反馈（逐人完成率与改版复测待补）。
- **AppliedAI & ServeTrace**：本地 `Qwen3.5-27B` + `BAAI/bge-small-zh-v1.5` 端到端走查；5 篇演示文档双路径正反对照（未授权 0/9、授权 9/9、公开 2/2，小语料规则验证）；模拟工具路由 10/10 + 三类混沌异常；ServeTrace 仅非流式（`stream=true` 拒返回 HTTP 400 `stream_not_supported`）、Memory / Redis 双限流后端 `3×200 + 2×429`。
- **ClassNote AI**：macOS 本地优先应用，`faster-whisper` 5 档模型（默认 Base），2026-09-07 真实故障驱动预检与三状态解耦，历史续录恢复找回约 76.8 分钟（4,609.14 秒 / 461 分片）有效录音，整堂课诚实标记为 `PARTIALLY_COMPLETED`，专业术语识别误差（WER）与长期留存待单独评估。
